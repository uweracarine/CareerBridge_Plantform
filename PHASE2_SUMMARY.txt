NEXT STEPS - PHASE 3: DATABASE DEVELOPMENT
================================================================================

When server npm install completes:

1. CREATE DATABASE:
   - Open MySQL Workbench or phpMyAdmin
   - Create database: careerbridge
   - Execute: CREATE DATABASE careerbridge CHARACTER SET utf8mb4;

2. GENERATE PRISMA CLIENT:
   cd server
   npx prisma generate

3. RUN MIGRATIONS:
   npx prisma migrate dev --name init

4. SEED DATA (Optional):
   npm run prisma:seed

5. VERIFY DATABASE:
   npx prisma studio  # Opens GUI browser interface

6. START DEVELOPMENT SERVER:
   npm run dev

Then in another terminal:
   cd client
   npm run dev
